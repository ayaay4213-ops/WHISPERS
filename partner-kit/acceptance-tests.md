# قائمة اختبار Whispers قبل التسليم

## الحسابات
- [ ] إنشاء حساب جديد والتحقق من وسيلة الاتصال.
- [ ] تسجيل الدخول والخروج واستعادة كلمة المرور.
- [ ] لا يمكن رؤية بيانات مستخدم آخر الخاصة أو تعديلها.

## الملف الشخصي والأعضاء
- [ ] حفظ الاسم والصورة والنبذة والدولة بعد إعادة الدخول.
- [ ] منع المعرّفات المكررة والمدخلات غير الصحيحة.
- [ ] البحث والمتابعة والمفضلة تعمل عبر الخادم.

## الغرف والصوت
- [ ] إنشاء غرفة وتعديلها وإغلاقها بصلاحيات المالك.
- [ ] مستخدمان على شبكتين مختلفتين يتصلان ويسمع كل منهما الآخر.
- [ ] كتم/إلغاء كتم، طلب المايك، قبول/رفض الطلب، إزالة عضو.
- [ ] لا يمكن دخول غرفة خاصة دون إذن.
- [ ] الدردشة والحضور يتحدثان دون إعادة تحميل الصفحة.

## العملات والهدايا
- [ ] أسعار الهدايا مصدرها الخادم لا المتصفح.
- [ ] لا يمكن أن يصبح الرصيد سالبًا.
- [ ] الطلب المكرر لا يخصم مرتين.
- [ ] دفتر المعاملات يطابق رصيد المرسل والمستقبل.
- [ ] مكافأة اليوم لا تمنح أكثر من مرة في اليوم وفق المنطقة الزمنية المعتمدة.

## الرسائل والسلامة
- [ ] الرسائل محفوظة ومحمية بين طرفي المحادثة.
- [ ] الحظر يمنع التواصل وفق السياسة.
- [ ] الإبلاغ ينشئ سجلًا للمراجعة.
- [ ] أدوات الإدارة مقصورة على الأدوار المخولة مع سجل تدقيق.

## النشر
- [ ] رابط HTTPS يفتح من جهاز غير جهاز المطور.
- [ ] لا توجد مفاتيح سرية في الملفات العامة أو سجلات المتصفح.
- [ ] صفحة الخصوصية والشروط ووسيلة التواصل متاحة.
- [ ] بيانات العرض تجريبية وموسومة بوضوح.
- [ ] اختبار الأداء والنسخ الاحتياطي ومراقبة الأخطاء مكتمل.
